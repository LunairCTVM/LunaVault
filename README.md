# LunaVault

Lightweight, modern and secure password manager with CustomTkinter GUI. Everything is compressed and encrypted into a single `.db` file.

---

## Features

- Single encrypted file (`vault.db`)
- AES-128-CBC + HMAC-SHA256 (Fernet)
- PBKDF2 key derivation (100k iterations)
- `zlib` compression
- Clickable URLs to open websites directly in your browser

---

## Installation

Install dependencies:
```bash
pip install customtkinter cryptography
```

---

## Usage

```bash
python LunaVault.py
```
